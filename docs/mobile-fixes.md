# Исправления мобильного интерфейса и Mini App

- Модалка больше не получает горизонтальное смещение одновременно от Tailwind и анимации. Центрирование остаётся постоянным при открытии и закрытии.
- Фокусом управляет модалка: на компьютере первое поле получает фокус без прокрутки, на телефоне фокус остаётся на диалоге до нажатия на поле. Убран отдельный `autoFocus` из редактора, который открывал клавиатуру раньше обработчика модалки.
- Уведомления раскрыты в отдельные строки. На телефоне сообщения веб-приложения расположены над нижней навигацией.
- Мобильная главная показывает основные задачи, до трёх привычек и два ближайших события. Показатели, проекты и вводная инструкция раскрываются отдельно. При смене ширины переключается сам вид, скрытые дубликаты записей не монтируются.
- Дополнительные действия на мобильных страницах находятся под кнопкой «Действия». Фильтры и массовый выбор задач раскрываются отдельно. Десктопные действия и фильтры доступны сразу.
- В Mini App сохранены быстрые вкладки. «Ещё» открывает все задачи, календарь, полные привычки, проекты, цели, итоги недели, финансы, настройки и подключённые направления бизнеса, партнёров и трейдинга. Разделы загружаются по запросу и используют общий редактор. Ссылки и переход назад работают внутри Mini App.
- Резервные копии и изображения загружаются с авторизацией, поэтому работают и при входе через токен Telegram без cookies. Изображения не записываются в постоянный кэш запросов. Истёкшая сессия Mini App запускает повторную авторизацию и очищает старый кэш.
- При ошибке быстрого добавления задачи Mini App сохраняет введённый текст. Сообщение загрузки изображения закрывается и после ошибки.

Проверки: `npm run check`, `npm test -w client`, `npm run build`, `npx playwright test`. Браузерные сценарии проверяют положение центра модалки во время анимации, отсутствие перекрытия двух уведомлений, мобильные раскрывающиеся элементы, переходы Mini App по разделам, создание задачи и скачивание копии без cookies. Подпись Telegram в браузерном тесте заменена тестовым ответом авторизации; последующие запросы работают с реальной серверной сессией. Поведение клавиатуры в приложении Telegram на физическом телефоне требует проверки на устройстве.
