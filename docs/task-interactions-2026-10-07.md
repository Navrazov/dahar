# Прямые действия с задачами — 7 октября 2026

## Что изменилось

- В web-списке задачи перетаскиваются за ручку: перед другой задачей, на сегодня/завтра/без срока, в проект. Порядок сохраняется на сервере. В доске перенос между колонками меняет статус.
- В Mini App список задач поддерживает перетаскивание пальцем, смену порядка и появляющиеся зоны «Сегодня», «Завтра», «Без срока», «Готово». Главные задачи остаются закреплёнными сверху. Простое касание названия по-прежнему открывает редактор.
- Календарь поддерживает перенос задач и событий между датами месяца, днями недели, строкой «весь день» и временными слотами по 15 минут. Временные события сохраняют длительность при переносе. При переводе события на весь день используется целое число дней; при переводе обратно во время — час. Есть создание задачи прямо из календаря и перенос задач без даты в календарь.
- Ручки работают мышью, касанием и клавиатурой: Space/Enter начинает перенос, стрелки выбирают место, Enter завершает, Escape отменяет. При переносе работает прокрутка; зоны подсвечиваются. Всплывающие зоны размещены в portal, чтобы анимация страницы не меняла их положение.
- Проект доступен в основных полях короткого редактора, в быстром создании web/Mini App и непосредственно в строке задачи Mini App. Не нужно открывать проект для создания задачи.
- В Mini App короткий свайп влево открывает удаление, длинный удаляет сразу. В течение восьми секунд есть «Отменить». Отмена восстанавливает исходную запись с тем же ID, проектом, чек-листом и планом через точное действие истории. Вертикальные жесты оставлены обычной прокрутке. Есть доступное меню действий без жестов: сегодня, завтра, убрать срок, удалить.
- Исправлено зависание индикатора очереди web после отправки изменений другой вкладкой: количество ожидающих изменений проверяется также при возвращении фокуса и каждые пять секунд.
- Если ответ сервера потерян при доступной сети, очередь повторно отправляется через секунду; ключ операции предотвращает создание дубликата.

## Исправленная логика дня

У задачи теперь есть `planned_date`, отдельно от срока `due_date` и звезды `focus_date`. Выбор главного записывает план на этот день. Снятие звезды сохраняет план, поэтому задача без срока или с будущим сроком остаётся в «Других делах сегодня». Её исходный срок сохраняется.

Перенос на другую дату обновляет план и срок и снимает главное другого дня. Изменение обычного срока в редакторе обновляет совпадающий план. Перестановка внутри одного дня сохраняет самостоятельный срок. Новая миграция `010_task_interactions` переносит существующий `focus_date` в план, добавляет `sort_order` и индекс. Списки дня, календарь и web-группы учитывают план.

Перестановка выполняется одной транзакцией и одним действием истории, проверяет владельца обеих задач и сохраняет относительный порядок остальных задач дня. Доступ к чужой записи отклоняется без частичного изменения. Серверный лимит трёх главных задач сохранён.

## Проверки

Локально прошли 131 серверный тест, 44 клиентских теста и все 33 браузерных сценария. Проверки типов, ESLint, Prettier, архитектуры FSD и сборка web и админки прошли.

Серверные регрессии проверяют снятие звезды с бессрочной задачи и будущего срока, намеренный перенос на завтра, сохранённый порядок и его отмену, изоляцию владельцев, удаление с точным восстановлением, изменение срока через редактор и независимый срок при сортировке.

Браузерные сценарии используют настоящие движения мыши и касания через Chromium CDP. Проверяются перетаскивание в проект, порядок после перезагрузки, перенос клавиатурой, даты календаря и сохранение длительности, проект при быстром создании Mini App, сохранение дня после снятия звезды, короткий/длинный свайп, отмена и перенос пальцем на завтра. Вход Telegram в браузере заменён тестовым ответом, последующие запросы идут через настоящий тестовый Bearer-токен.

Жесты на физических iPhone/Android внутри Telegram отдельно не проверялись. Mini App по-прежнему требует соединение для записи; постоянная офлайн-очередь относится к web-приложению.
